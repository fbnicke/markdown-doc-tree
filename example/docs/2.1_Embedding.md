# Embedding

Import the viewer entry point once:

```typescript
import "markdown-doc-tree/viewer";
```

Then add the Web Component:

```html
<markdown-doc-tree
  manifest-url="/documentation/docs-manifest.json"
  navigation-mode="internal"
  initial-document="1"
></markdown-doc-tree>
```

## Navigation modes

Use `internal` when embedding the viewer inside an application:

```html
<markdown-doc-tree
  navigation-mode="internal"
></markdown-doc-tree>
```

Use `hash` when document selection should be reflected in the page URL:

```html
<markdown-doc-tree
  navigation-mode="hash"
></markdown-doc-tree>
```
