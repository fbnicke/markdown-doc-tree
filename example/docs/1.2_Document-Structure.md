# Document Structure

Place Markdown documents directly inside the documentation root.

```text
docs/
├─ 1_Getting-Started.md
├─ 1.1_Installation.md
├─ 1.2_Document-Structure.md
├─ 2_Viewer.md
└─ images/
   └─ example-viewer.png
```

The numeric filename prefix controls ordering and hierarchy:

| Filename | Document ID | Parent |
| --- | --- | --- |
| `1_Getting-Started.md` | `1`         | none   |
| `1.1_Installation.md`  | `1.1`       | `1`    |
| `2_Viewer.md`          | `2`         | none   |

Subdirectories are reserved for images and other assets.

Relative image paths work in both the viewer and generated PDF:
