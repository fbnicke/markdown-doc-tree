# Local Preview

Open a documentation directory directly in the local viewer:

```bash
npx markdown-doc-tree serve ./docs
```

The command:

1. validates the numbered Markdown structure
2. generates a temporary documentation manifest
3. starts a local web server
4. opens the viewer in the default browser

Use a custom port:

```bash
npx markdown-doc-tree serve ./docs --port 8080
```

Suppress automatic browser opening:

```bash
npx markdown-doc-tree serve ./docs --no-open
```
