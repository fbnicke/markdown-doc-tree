# Styling

The viewer uses shadow DOM to isolate its internal styles.

Consuming applications can customize exposed elements through CSS shadow parts:

```css
markdown-doc-tree {
  min-height: 40rem;
  color: #202124;
  background: #ffffff;
  font-family: Arial, sans-serif;
}

markdown-doc-tree::part(sidebar) {
  background: #f6f8fa;
}

markdown-doc-tree::part(navigation-link-active) {
  color: #ffffff;
  background: #0b57d0;
}

markdown-doc-tree::part(content) {
  width: min(75rem, 100%);
  padding: 3rem;
}
```

Commonly used public parts include:

| Part                     | Purpose                     |
| ------------------------ | --------------------------- |
| `layout`                 | Root viewer layout          |
| `sidebar`                | Navigation sidebar          |
| `navigation-link`        | Document links              |
| `navigation-link-active` | Selected document link      |
| `content`                | Rendered Markdown container |

The host element controls inherited properties such as the font, text color, and background.
