# PDF Branding

Pass an additional stylesheet to customize the generated manual:

```bash
npx markdown-doc-tree pdf ./docs \
  --output ./output/branded-manual.pdf \
  --title "Example Documentation" \
  --stylesheet ./example/pdf-theme.css
```

A PDF stylesheet can define typography, colors, spacing, page margins, and other print-specific presentation.

```css
:root {
  font-family: Arial, sans-serif;
  color: #1f2937;
}

h1,
h2 {
  color: #0b57d0;
}
```

Viewer styling and PDF styling are deliberately separate because interactive browser layouts and printed pages have different requirements.
